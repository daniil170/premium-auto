# Premium Auto

Premium Auto is a modern multi-page website dedicated to luxury and high-performance automobiles. The project presents a curated collection of premium vehicles and provides visitors with information about design, performance, and engineering behind some of the most iconic cars in the automotive industry.

The website was built as a frontend project to practice layout design, page structure, and user interface development using HTML and CSS.

---

## Overview

Premium Auto is designed as a clean and visually engaging platform where users can explore premium cars in a simple and organized way. The website focuses on minimalistic design, dark luxury styling, and clear navigation between sections.

Visitors can browse a small catalog of selected vehicles, read information about the project, explore services provided by the platform, and contact the team through a simple contact form.

The goal of this project is to demonstrate fundamental frontend development skills such as layout creation, responsive structure, and UI design.

---

## Features

* Multi-page website structure
* Modern dark luxury design
* Car catalog with multiple vehicle cards
* Hover animations and interactive UI elements
* About page with detailed project description
* Services page explaining platform features
* Contact page with contact information and form
* Clean navigation and structured layout
* Hosted using GitHub Pages

---

## Pages

### Home

The main landing page introduces the Premium Auto platform and presents a catalog of selected luxury vehicles.

### About

The About page explains the purpose of the project, the philosophy behind premium automotive engineering, and the idea behind the curated vehicle collection.

### Services

This page highlights the key features of the platform, including the vehicle catalog, automotive insights, and the digital experience created for visitors.

### Contact

The Contact page allows visitors to reach out through a simple contact form and provides general contact information.
